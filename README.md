
# Estudos de Python | Luiz Otávio Miranda

## Sobre o Projeto

Este repositório foi criado com o objetivo de documentar minha jornada de aprendizado na linguagem de programação Python, acompanhando o curso ministrado por Luiz Otávio Miranda.

Aqui serão registrados os conhecimentos adquiridos durante as aulas, os exercícios realizados e as aplicações práticas desenvolvidas ao longo dos estudos.

A proposta é construir uma base sólida em programação, aprimorando gradualmente meu raciocínio lógico, minha capacidade de resolver problemas e minha compreensão dos principais conceitos da linguagem.

## Objetivos

Os principais objetivos deste repositório são:

- Aprender os fundamentos da linguagem Python.
- Desenvolver o raciocínio lógico aplicado à programação.
- Praticar a resolução de problemas por meio de algoritmos.
- Compreender a sintaxe e o funcionamento dos recursos da linguagem.
- Aplicar os conhecimentos adquiridos em exercícios e projetos práticos.
- Desenvolver boas práticas de escrita e organização de código.
- Acompanhar minha evolução e identificar pontos que precisam ser aprimorados.
- Construir uma base para estudos futuros em desenvolvimento de software e cibersegurança.

## Sobre o Aprendizado

O aprendizado será desenvolvido por meio da combinação entre teoria e prática. Durante o curso, os conceitos apresentados serão explorados por meio de exemplos, exercícios e experimentações com o código.

A intenção não é apenas reproduzir os exemplos das aulas, mas também compreender como cada recurso funciona, por que ele é utilizado e em quais situações pode ser aplicado.

Os exercícios serão utilizados para reforçar os conteúdos estudados, desenvolver a autonomia na programação e aprender a identificar e corrigir erros.

Conforme o aprendizado avançar, os conhecimentos adquiridos serão aplicados em pequenos projetos, permitindo trabalhar com problemas cada vez mais complexos.

## Conteúdos Estudados

Ao longo dos estudos, serão abordados conceitos fundamentais da programação com Python, incluindo:

- Fundamentos da programação e algoritmos.
- Variáveis e tipos de dados.
- Entrada e saída de informações.
- Operadores aritméticos, relacionais e lógicos.
- Conversão e manipulação de tipos de dados.
- Estruturas condicionais, como `if`, `elif` e `else`.
- Estruturas de repetição, como `for` e `while`.
- Estruturas de dados, como listas, tuplas e dicionários.
- Funções e reutilização de código.
- Tratamento de erros e exceções.
- Programação orientada a objetos.
- Desenvolvimento de pequenos projetos práticos.

Os conteúdos serão estudados progressivamente, conforme o avanço no curso. A lista representa os tópicos previstos para aprendizado, e não necessariamente conteúdos já concluídos.

## Ferramentas Utilizadas

Durante o desenvolvimento dos estudos, serão utilizadas ferramentas que auxiliam na escrita, execução, organização e documentação do código.

**Python:** linguagem de programação utilizada para os exercícios e projetos.

**Visual Studio Code:** editor utilizado para escrever, executar e organizar os códigos.

**Git:** sistema de controle de versão utilizado para acompanhar as alterações realizadas nos arquivos.

**GitHub:** plataforma utilizada para armazenar o repositório, registrar a evolução dos estudos e compartilhar os projetos.
